# OOps

OOps 是一个高性能 GPU 算子库，旨在加速 OFold、ODesign 等生物分子基础模型。
OOps 充分发挥硬件效率，显著加速训练和推理，突破超长序列的显存瓶颈，让 GPU 在常规框架显存不足的场景下继续运行。

## 安装

```shell
pip install ooperators
```

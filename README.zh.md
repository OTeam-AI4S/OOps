# [OOps](https://oops.valtech.ai/zh/)

> [!TIP]
> More OOps, zero OOMs.

OOps 为生物分子模型提供 PyTorch 算子。它是 [OFoldX](https://github.com/OTeam-AI4S/OFoldX) 的算子后端，也可直接用于 PyTorch 程序。

## 快速开始

从 PyPI 安装：

```shell
pip install ooperators
```

如果需要尚未发布的修改，可以从源码安装：

```shell
pip install git+https://github.com/OTeam-AI4S/OOps
```

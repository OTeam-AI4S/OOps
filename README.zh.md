# OOps

> [!TIP]
> 将生物分子建模加速到硬件极限。

[![许可证：专有](https://img.shields.io/badge/License-Proprietary-red.svg)](LICENSE)

OOps 是 OFoldX 使用的算子库。
它将注意力、三角更新等生物分子模型中的主要计算实现为支持训练和推理的高性能 PyTorch 算子。

## 安装

```shell
pip install git+https://github.com/valhalla-engineering/OOps
```

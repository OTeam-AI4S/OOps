# OOps

> [!TIP]
> Accelerate Biomolecular Modeling to the Limits of Hardware.

[![License: Proprietary](https://img.shields.io/badge/License-Proprietary-red.svg)](LICENSE)

OOps is the operator library behind OFoldX.
It reimplements the operations that dominate the cost of biomolecular models, such as attention and triangle updates, as fast PyTorch operators for both training and inference.

## Installation

```shell
pip install git+https://github.com/valhalla-engineering/OOps
```
